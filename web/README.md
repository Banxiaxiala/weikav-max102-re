# MAX102 本地配置工具使用说明

在浏览器里改键 + 看电量，不依赖任何在线服务。

---

## 一、准备

### 1. 刷补丁固件（看电量才需要）

电量功能需要补丁固件。**改键 / 调灯效在原厂固件上也能用。**

补丁固件不入库，现场构建：

```bash
# 在仓库根目录执行（下文都用相对路径）
cd weikav-max102

py -3.13 patch-sdk/tools/build.py patch-sdk/patches/battery
py -3.13 patch-sdk/tools/equiv.py --verify patch-sdk/out/max102_battery.bin

# 进 DFU：按住 FN → 按住右 Shift → 点一下 ESC
wb32-dfu-updater_cli.exe -l
wb32-dfu-updater_cli.exe -D patch-sdk\out\max102_battery.bin
wb32-dfu-updater_cli.exe -R
```

> ⚠️ **不要加 `-s 0x08000000`**：此版工具带这个参数会静默失败（exit 64、无输出）。
> 省略 `-s` 时默认就是 `0x08000000`。

### 2. 启动（推荐用启动器）

**必须是 Chromium 内核**（WebHID 支持）。Firefox / Safari 不行。

#### 方式 A：双击启动器（最简单）

```
启动配置工具.cmd        ← 仓库根目录，双击
```

它会自动：找 Python 3.13 → 起本地 HTTP 服务 → 打开浏览器。
关掉黑窗口即停止。

#### 方式 B：命令行

```bash
py -3.13 -X utf8 tools/launch.py                 # 起服务 + 开浏览器
py -3.13 -X utf8 tools/launch.py --with-status   # 顺便打印设备状态
py -3.13 -X utf8 tools/launch.py --no-browser    # 只起服务
py -3.13 -X utf8 tools/launch.py -p 9000         # 换端口
```

#### 为什么不能直接双击 index.html

WebHID 要求「安全上下文」：

| 打开方式 | WebHID 可用？ |
|---|---|
| `file:///.../index.html`（双击） | ❌ **Chrome/Edge 直接禁用** |
| `http://127.0.0.1:8777/` | ✅ |
| `http://localhost:8777/` | ✅ |
| `http://192.168.x.x:8777/` | ❌ 非回环地址不算安全上下文 |

所以必须起本地服务，直连 `file://` 无论怎么改都不行。

#### 2.4G 无线也能用

插着接收器、不插 USB 线，改键 / 看电量 / 调灯效全都能做。
启动器会连到 `MAX102-2.4G`，功能和有线完全一致。

### 3. 键盘设置

- USB 线连接
- 电源开关 ON
- 按 **FN + T** 切到有线模式

## 二、使用

### 连接

点右上角 **「连接键盘」** → 浏览器弹窗选设备（名字是 `MAX102`）→ 允许。

连接成功后：
- 状态徽章变绿 `已连接`
- 自动读取 5 层键位（约 3 秒）
- 左侧开始显示电量

### 看电量

左侧面板每 3 秒自动刷新：

| 项 | 说明 |
|---|---|
| **电量** | 0–100%，下方彩色进度条 |
| **连接状态** | 未初始化 / 配对中 / 已连接 / 已断开 / 被拒绝 |
| **模块版本** | FR8003A 固件版本 |
| **指示灯** | Caps / Num / Scroll |

> 电量来源：主控每 3 秒问 FR8003A 一次（`0xA6 0x53`），
> 模块回 `0x5C <0-100>`。网页通过**新增的 `cmd 20`（0x14）**读取。
> 与键盘上按 `FN + BATQ` 点亮的 LED 段数一致。

### 改键

1. 上方选择层（层 0 基础 / 层 1 FN / 层 2 / 层 3 / 层 4 BOOT）
2. 点键盘上任意键
3. 弹窗里搜索或浏览键位分组
4. 点选即写入

改动立即生效并写进键盘 EEPROM，拔线不丢。

**颜色含义：**

| 颜色 | 含义 |
|---|---|
| 灰 | 未改动 |
| 绿 | 本次会话改动过 |
| 虚线框 | 该矩阵位置无键（预留位） |

### 其他按钮

| 按钮 | 作用 |
|---|---|
| **重读键位** | 从头读一遍 5 层（改乱了可以看实际值） |
| **恢复默认** | 发 `EEPROM_RESET`，清空所有自定义设置 |
| **进入刷机模式** | 发 `BOOTLOADER_JUMP`，键盘直接进 DFU |

## 三、键位分组说明

| 分组 | 内容 |
|---|---|
| 基础 | 回车、退格、方向键、小键盘、截屏等 |
| 字母 / 数字 / 功能键 | 常规键 |
| 修饰键 | Ctrl / Shift / Alt / Win（含 `0x52xx` 修饰位形式） |
| 多媒体 | 播放控制、浏览器、计算器 |
| 音量/亮度 | 音量、静音、屏幕亮度 |
| 层/特殊 | `▽MO(n)` `▽TG(n)` `▽TO(n)` `▽LT(n,kc)` `QK_BOOT` |
| **MAX102 自定义** | **BT1/BT2/BT3 / 2.4G / USB / WHITE / BATQ / NOSEC / REC** |
| 灯效 (UG_*) | 灯效开关、切换、色相、饱和、亮度、速度 |

> `MAX102 自定义` 对应固件里的 `QK_KB` 区（`0x7E00`–`0x7E08`）。
> 官方 VIA JSON 只声明了 9 个，但固件实际支持 24 个（`0x7E00`–`0x7E17`），
> 本工具只列了确认可用的前 9 个。

## 四、与补丁的关系

| 功能 | 需要补丁固件吗 |
|---|---|
| 改键 / 读键 | ❌ 原厂固件即可 |
| **看电量** | ✅ **必须刷补丁** |

补丁**新增**了 VIA 的 `cmd 20`（0x14）。原厂该号越界、回 `0xFF`，改成有效命令不影响任何现有功能；原厂 19 条命令（含 cmd 6「恢复默认 keymap」）行为完全不变。
所以如果你之前用官方网页驱动做过"批量设色"之类的操作，刷补丁后会失效——但那功能官方界面本来就没有入口。

### 回退到原厂

```bash
# DFU 模式
wb32-dfu-updater_cli.exe -D firmware\max102_stock_trimmed.bin -s 0x08000000
wb32-dfu-updater_cli.exe -R
```

回退后本工具仍可改键，只是电量显示为 `--`。

## 五、常见问题

### 点了「连接键盘」没反应

1. 确认浏览器是 Chrome / Edge
2. 确认键盘在**有线模式**（FN + T）
3. 页面必须是 `http://` 或 `file://`，不能是 `about:blank`
4. 之前拒绝过权限 → 点地址栏左边的锁图标 → 重置 HID 权限

### 电量一直显示 `--`

- 说明键盘没响应 `cmd 20`（0x14）
- 可能原因：① 没刷补丁固件 ② 选了错误的 HID 接口
- 改键正常但电量不动 = 没刷补丁；先确认响应首字节是 `0x14` 而不是 `0xFF`

### 改键后键盘没变化

- 有些位置是 `▽TRNS`（穿透），改了如果下层也是同一个键，看起来没变
- 切到对应层确认
- 用「重读键位」看键盘里真实值

### 读层数时卡住

蓝牙/2.4G 模式下 VIA 通道可能不通。切回 USB 有线模式（FN + T）。

## 六、技术细节（给要改代码的人）

### 协议

```
REPORT_SIZE = 33
请求: [0, cmd, ...payload, 补 0]
响应: [0, cmd, ...data, 补 0]
```

### 本工具用到的命令

| cmd | 名称 | 用途 |
|---|---|---|
| 1 | GET_PROTOCOL_VERSION | 握手，应为 12 |
| 4 | GET_KEYCODE | 读单个键（用于写入后读回验证） |
| 5 | SET_KEYCODE | 写单个键 |
| **20** | **GET_BATTERY** | **补丁新增**（原厂该号越界回 0xFF） |
| 10 | EEPROM_RESET | 恢复默认 |
| 11 | BOOTLOADER_JUMP | 进 DFU |
| 17 | GET_LAYER_COUNT | 读层数（=5） |
| 18 | KEYMAP_GET_BUFFER | **批量读键位**（每层 9 次请求） |

### 电量响应布局

```
r[4] = 电量 0-100
r[5] = 连接状态 0=NONE 1=PAIRING 2=CONNECTED 3=DISCONNECTED 4=REJECT
r[6] = 模块固件版本
r[7] = 指示灯位图  bit0=Caps bit1=Num bit2=Scroll
```

### 批量读键位

```
请求: [0, 18, offset_hi, offset_lo, size]     size ≤ 28
响应: [0, 18, ?, ?, data...]                   data 从 r[4] 开始
```

- 每层 114 键 × 2 字节 = 228 字节
- 每层偏移 `L * 228`
- 每次读 28 字节 → 每层 9 次请求 → 5 层共 45 次

### 键码编码

- 大端（`0x0029` = ESC）
- 矩阵 `6 行 × 19 列`，扁平索引 = `row * 19 + col`
