## 一、卡住项（缺了没法写出能跑的固件）

### ① 矩阵 6×19 行/列引脚 ⭐ 最高优先

| 项 | 说明 |
|---|---|
| 要什么 | 6 个行线 GPIO、19 个列线 GPIO，及二极管方向（ROW2COL / COL2ROW） |
| 为什么 | QMK 的 `matrix_pins` 必需，没有它键盘完全不能用 |
| 怎么弄 | 万用表通断档：一端固定一个按键的 row 脚，另一端点各候选 GPIO，看哪个和按键矩阵引脚通 |
| 更快的办法 | 按键按下时，主控对应两个脚会短接。用万用表二极管档逐键测，能一次推出整张表 |
| 备选 | 若 PCB 上有测试点或丝印标注（如 `R0`/`C0`），拍照即可 |

### ② UART 引脚最终确认 ⭐

| 项 | 说明 |
|---|---|
| 要什么 | FR8003A 的 TX/RX 分别接到 WB32 哪个引脚 |
| 现状 | 固件反推为 **PC10 / PC11**（`FUN_0800be84` 里配了 bit10 和 bit11），但存在 `0x40000800` vs 官方 `GPIOC=0x40000C00` 的基址疑点，未 100% 锁定 |
| 怎么弄 | 万用表通断：FR8003A 的 UART 脚 → WB32 对应脚；或直接看 PCB 走线 |
| 影响 | 只影响移植；**不影响电量协议本身**（协议已确认） |

### ③ RGB 灯珠类型与数据脚

| 项 | 说明 |
|---|---|
| 要什么 | 型号（WS2812B / SK6812 / 其他）、数量、数据脚、是否有 MOS 供电开关 |
| 为什么 | `RGB_MATRIX_DRIVER` 选择，以及那 10 颗电量灯柱（LED 索引 35–44）的定位 |
| 怎么弄 | 看灯珠丝印（4 脚，通常 5×5mm）；数据脚用通断测 |
| 附带收获 | 能确认电量柱的 10 颗灯具体在键盘哪个位置 |

## 二、做「充电状态上报」才需要

### ④ X14076 周边的连接关系

| 项 | 说明 |
|---|---|
| 要什么 | `CHRG`（充电中）/ `STDBY` 或 `DONE`（充满）两个脚接到 **WB32 的哪个 GPIO**，还是接到 **FR8003A** |
| 为什么 | 决定充电状态由谁检测、谁上报 |
| 怎么弄 | 高清照片（能看到走线）+ 万用表通断 |
| 已知旁证 | 固件里定义了 `0xA6 0x64/0x65/0x66`（充电中/停止/完成）三条命令，但**一次都没发过** → 说明原厂自己也没做充电检测 |
| 最可能的情况 | 状态脚只接了一颗 LED，或悬空。那么要上报就得**自己飞线**到 WB32 一个空 GPIO |

### ⑤ X14076 型号确认 / datasheet

| 项 | 说明 |
|---|---|
| 现状 | `X14076` + `B01A`（疑批次码），公开渠道查不到 datasheet |
| 猜测 | `X` 前缀 + 国产，疑似赛芯（Xysemi）体系 |
| 怎么弄 | 拍 X14076 本体特写（侧光 45°，丝印要清晰）+ 周边阻容布局 |

## 三、可选（有则省事很多）

### ⑥ PCB 正反面高清照片

必须能看清位号（`R`/`C`/`U`/`Q` 丝印）。重点区域：

1. FR8003A 及其屏蔽罩（若可透光/撕开更好）
2. X14076 及周边阻容
3. 电池排线座
4. SWD 焊盘（`CON2`：GND / SWCLK / SWDIO / 3.3V）
5. 你提到的烧录调试串口（`CON3`？）

### ⑦ 原厂原理图 / 维修点位图

概率低，但值得问一下售后。有的话上面 ①–⑤ 全部省掉。

### ⑧ UART 实机嗅探（可选，但很有价值）

| 项 | 说明 |
|---|---|
| 做法 | USB-TTL 串口模块，**只接 RX**（并到 FR8003A 的 TX → WB32 的 RX 那根线），115200 8N1 |
| 期望看到 | 每 3 秒：`A6 53 F9`（查询）→ `5C <电量> <sum>` → `61 0D 0A`（ACK） |
| 价值 | 把「从固件反汇编推断的」变成「实机抓到的」，零风险（只收不发） |
| 注意 | **不要接地线以外的线**，避免两个 TX 打架 |

## 四、完全不需要的东西（别再花时间）

| 曾经以为需要 | 实际情况 |

| ❌ 改 HID 描述符才能上报 | **不必须**。VIA 私有命令就够了，且更安全 |
| ❌ 找 X14076 datasheet 才能做电量上报 | **不需要**。电量由 FR8003A 测，与充电 IC 无关 |

## 六、如果你只有时间做一件事

**做 ①（矩阵引脚）。**

因为：
- 它是唯一"必须测"的硬骨头，测法确定（万用表 + 逐键）
- 有了它，就能编译出**第一个能用的自制固件**
- 电量代码可以同时放进去（`md_getp_bat()` 现成可用），一次刷机两个功能都拿到
- ②③ 可以边用边补（UART 试错成本低，RGB 不影响基本可用）

> 详细实现方案见 [`BATTERY.md`](BATTERY.md)。
