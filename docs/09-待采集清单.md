# 还需要你提供什么 —— 待采集清单

> 目的：列出**改固件**还没拿到的硬件信息，按「不做就卡住」→「做了更好」排序。
> 每条都写了**为什么要**和**怎么弄**。
>
> 状态更新：2026-11-10（电量上报已通过二进制补丁落地，**当前没有卡住项**）

## 零、先说结论：现在什么都不缺

电量上报已经做完并验证过（见 [`电量补丁方案.md`](07-电量补丁方案.md)）。
它需要的全部信息都已经从固件里挖出来了，**不需要拆机、不需要万用表、不需要逻辑分析仪**。

下面第一节列的是**下一个功能**（充电状态）真正卡住的地方；
第二节列的是"只在将来自己写固件时才需要"的信息，现在不做也不影响任何事。

## 一、做「充电状态上报」才需要（下一个功能）

### ① X14076 周边的连接关系 ⭐ 当前唯一真正的卡点

| 项 | 说明 |
|---|---|
| 要什么 | `CHRG`（充电中）/ `STDBY` 或 `DONE`（充满）两个脚接到 **WB32 的哪个 GPIO**，还是接到 **FR8003A** |
| 为什么 | 决定充电状态由谁检测、由哪边上报；接错方向就是白写补丁 |
| 怎么弄 | 高清照片（能看到走线）+ 万用表通断 |
| 已知旁证 | 固件里定义了 `0xA6 0x64/0x65/0x66`（充电中/停止/完成）三条命令，但**一次都没发过** → 说明原厂自己也没做充电检测 |
| 最可能的情况 | 状态脚只接了一颗 LED，或悬空。那么要上报就得**自己飞线**到 WB32 一个空 GPIO |

### ② X14076 型号确认 / datasheet

| 项 | 说明 |
|---|---|
| 现状 | `X14076` + `B01A`（疑批次码），公开渠道查不到 datasheet |
| 猜测 | `X` 前缀 + 国产，疑似赛芯（Xysemi）体系 |
| 怎么弄 | 拍 X14076 本体特写（侧光 45°，丝印要清晰）+ 周边阻容布局 |
| 备注 | 就算查不到 datasheet，只要测出 ①② 的连线关系就能开工 |

## 二、只在"将来自己写固件"时才需要（现在不做）

> 这些是移植 QMK 才需要的输入。本项目不走那条路，
> 所以它们**不影响当前任何一个补丁**。列在这里只是备忘。

### ③ 矩阵 6×19 引脚的万用表实测

| 项 | 说明 |
|---|---|
| 现状 | 固件已推出一份完整候选表（[`硬件引脚.md`](05-硬件引脚.md) §1），万用表只是交叉验证 |
| 要什么 | 6 个行线 GPIO、19 个列线 GPIO，及二极管方向（已从固件判定 **COL2ROW**） |
| 为什么现在不需要 | 改固件不碰矩阵扫描逻辑，引脚是哪几个都不影响补丁 |
| 怎么弄 | 万用表通断档：固定一个按键的 row 脚，端点各候选 GPIO；或看 PCB 丝印 `R0`/`C0` |

### ④ UART 引脚最终确认

| 项 | 说明 |
|---|---|
| 现状 | 固件反推为 **PC10 / PC11**，存在 `0x40000800` vs `GPIOC=0x40000C00` 的基址疑点，未 100% 锁定 |
| 影响 | 只影响"自己写 transport"；**改固件只需协议，不需要引脚** |

### ⑤ RGB 灯珠类型与数据脚

| 项 | 说明 |
|---|---|
| 要什么 | 型号（WS2812B / SK6812 / 其他）、数量、数据脚、是否有 MOS 供电开关 |
| 为什么现在不需要 | 电量补丁只读数值，不碰灯效；想改灯效才需要 |
| 怎么弄 | 看灯珠丝印（4 脚，通常 5×5mm）；数据脚用通断测 |
| 附带收获 | 能确认电量灯柱（LED 索引 35–44）在键盘上的具体位置 |

## 三、可选（有则省事很多）

### ⑥ PCB 正反面高清照片

必须能看清位号（`R`/`C`/`U`/`Q` 丝印）。重点区域：

1. X14076 及周边阻容（**当前最有用**）
2. 电池排线座
3. FR8003A 及其屏蔽罩
4. SWD 焊盘（`CON2`：GND / SWCLK / SWDIO / 3.3V）
5. 烧录调试串口（`CON3`？）

### ⑦ 原厂原理图 / 维修点位图

概率低，但值得问一下售后。有的话 ①② 全部省掉。

### ⑧ UART 实机嗅探（可选，只收不发）

| 项 | 说明 |
|---|---|
| 做法 | USB-TTL 串口模块，**只接 RX**（并到 FR8003A 的 TX → WB32 的 RX 那根线），115200 8N1 |
| 期望看到 | 每 3 秒：`A6 53 F9`（查询）→ `5C <电量> <sum>` → `61 0D 0A`（ACK） |
| 价值 | 把"从反汇编推断"变成"实机抓到的"，零风险 |
| 注意 | **不要接 TX**，避免两个输出打架 |

## 四、完全不需要的东西（别再花时间）

| 曾经以为需要 | 实际情况 |
|---|---|
| ❌ 逻辑分析仪抓无线总线协议 | **不需要**。UART `md` 协议已 100% 还原 |
| ❌ 拆屏蔽罩认模块型号 | **不需要**。已确认 Freqchip FR8003A |
| ❌ 逆向 FR8003A 固件才能做电量 | **不需要**。电量走 UART，主控侧改固件即可 |
| ❌ 改 HID 描述符才能上报 | **不必须**。VIA 私有命令就够了，且更安全 |
| ❌ 找 X14076 datasheet 才能做电量上报 | **不需要**。电量由 FR8003A 测，与充电 IC 无关 |
| ❌ 测完矩阵引脚才能让键盘能用 | **不需要**。原厂固件里的扫描逻辑原封不动 |

## 六、如果你只有时间做一件事

**做 ①（X14076 状态脚接到哪）。**

因为：

- 它是唯一还卡着的硬件信息，测法确定（照片 + 通断）
- 有了它，"充电中 / 已充满"两个状态就能做成 VIA 命令，和电量走同一条路
- 其余项（③④⑤）全都是移植专用，改固件用不上

> 详细实现方案见 [`电量链路.md`](06-电量链路.md)。
