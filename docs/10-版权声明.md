## 2. 固件二进制（`firmware/`）

### 2.1 版权状态

`firmware/max102_stock_256k.bin` 和 `firmware/max102_stock_trimmed.bin` 是
**LEKU / Weikav 出厂烧录的固件**，经本机设备的 ROM DFU bootloader 读取获得。

经反编译确认，该固件是 **QMK 衍生作品**，证据：

- bootloader 跳转代码与 QMK 上游 `platforms/chibios/bootloaders/wb32_dfu.c` **逐字对应**
- VIA 协议版本 12，45 条标准命令 + 厂家私有扩展
- 由 `newlib` + `arm-none-eabi-gcc` 构建，路径深度 8 层（`qmk_firmware/tmk_core/...` 结构）
- QMK 官方已将其列入 [license_violations](https://docs.qmk.fm/license_violations) 第 52 行

因此其**许可应推定为 GPL-2.0**（QMK 项目使用的许可证），而非"保留所有权利"。

### 2.2 ⚠️ 源码缺失 —— 厂商违规

GPL-2.0 §3 要求分发二进制时**同时提供完整对应源码**，或提供三年有效的书面承诺。

**LEKU / Weikav 从未公开该固件的源码，也未提供任何书面承诺。**
这正是 QMK 官方暂停其全部 PR 的原因（[issue #24085](https://github.com/qmk/qmk_firmware/issues/24085)）。

**本仓库的立场**：支持 QMK 的 GPL 诉求。此处标注 GPL-2.0 是对事实的陈述，
**不是**为厂商的违规行为背书，也**不意味着**本仓库已满足 §3 的源码提供义务
（我们没有源码，无法满足）。

### 2.3 为什么仍然收录

原厂不提供任何固件下载渠道，而固件是**设备变砖后唯一的恢复手段**。
硬件社群长期惯例是：为互操作性与设备修复目的收录固件副本，并附完整来源说明与校验值。

如果你需要更保守的方案，可以只保留 `max102_stock_trimmed.bin`（68KB 有效代码区），
全片 256KB 仅保留 MD5 与读取命令。校验值已在下方给出。

### 2.4 使用限制

你**可以**：

- 用于恢复你自己拥有的 MAX102 键盘
- 用于研究、分析、教学
- 用于验证本文档中的地址与结论
- 按 GPL-2.0 的条款再分发（但同样受 §2.2 源码缺失问题约束）

你**不可以**：

- 用于仿制、批量生产同类产品
- 用于商业销售或作为商业服务的一部分
- 声称这是你的作品
- 移除或篡改其中的版权信息

## 3. 厂商 VIA 定义（`tools/max102_via.json`）

该文件由厂商随键盘提供（原发布渠道为 Google Drive 分享链接），用于让 VIA 网页
识别键盘布局。它属于**厂商的配置数据**，不是开源代码，也没有附带任何许可声明。

**状态不明**：无法确定它是 GPL-2.0 的一部分（若由 QMK 构建流程生成）
还是厂商独立产出的专有数据。按最保守方式处理 —— **不在 MIT 覆盖范围内**。

收录原因：**没有它，VIA 无法识别这块键盘**，本项目的所有键位分析也就无法复现。

同样受 §2.6 移除条款约束。

## 4. 关于反编译产物

本仓库**不包含**原厂固件的完整反编译输出（`decompiled_all.c` / `functions.asm`，
共约 1 MB、520 个函数）。那些文件属于原厂固件的改编形式，再分发风险显著高于
原始二进制，因此未纳入。

**你可以自己生成**：仓库提供了 `scripts/Max102Post.java` 与
`scripts/ExportDecomp.java`，配合 `firmware/` 中的二进制，按
[调试指南.md §6](03-调试指南.md#6-ghidra-静态调试工作流) 的步骤即可在本地产出同样的结果。

分析结论（函数地址、RAM 布局、协议字段）已在 [反汇编.md](04-反汇编.md)
中以**事实性描述**形式给出，不构成对原厂代码的再分发。

## 5. 法律与合规说明

### 5.1 研究目的

本项目是**个人硬件研究**，目标是为一台自己购买的键盘移植开源 QMK 固件。
所有固件读取均在**本人拥有的设备**上进行。

### 5.2 关于逆向的合法性

- 对**自己拥有的设备**进行固件读取与互操作性逆向，在多数司法辖区属合法行为
- 本项目使用的是**厂商官方提供的 ROM DFU 接口**（`wb32-dfu-updater`），
  **未绕过任何技术保护措施**
- 未破解加密、未规避授权校验、未获取任何用户数据

### 5.3 与 QMK 的关系

固件基于 QMK（GPL-2.0），因此本仓库将固件二进制标注为 GPL-2.0。
QMK 官方将 Weikav 列入
[license_violations](https://docs.qmk.fm/license_violations) 名单（第 52 行），
原因是厂商销售基于 QMK 的产品却不提供源码。

**本项目立场**：支持 QMK 的 GPL 诉求，希望 Weikav 履行开源义务。
本仓库不包含厂商源码（因为厂商从未发布过），因此**无法满足 GPL-2.0 §3**
的源码提供义务 —— 这一点已在 §2.2 明确说明，不做隐瞮。

### 5.4 无担保

所有内容按"现状"提供，**不提供任何明示或暗示的担保**。
刷机、拆机、焊接均有损坏设备的风险，**后果自负**。
